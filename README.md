# Bidri Crafts — WordPress store

Live at https://bidricrafts.in (WordPress + WooCommerce on Hostinger).

| Folder | What it is |
|---|---|
| `theme/bidri-crafts` | The block theme |
| `setup/` | Setup script, page content, product data and photos, pre-launch check |
| `setup/plugins/bidri-studio` | **Studio**, the owner's shop panel (`/studio`) |
| `docs/` | Launch guide, owner guide |
| `android/` | The Studio Android app (notifications for orders, exchanges, low stock) |

Build the upload zips with `bash scripts/package.sh` (output in `dist/`), then follow `docs/START-HERE.txt`.
